# Almost Done, Forever

One loading-screen tip, 148 characters — for stressed developers and AI coding agents.

> Tip: if your agent has been almost done for 20 minutes, it is not almost done — go drink some water, it will still be almost done when you get back.

The joke is about both audiences at once: the developer waiting and the agent stalling. It is fresh — no coffee, no deadline, no compile joke — and the advice is real: step away, drink some water, it will still be almost done when you return. The laugh comes from recognition, not a pun: anyone who has watched a progress bar sit at "almost done" has lived this exact twenty minutes, on both sides of the keyboard.

`main.ts` (Node, no dependencies, no network, deterministic) writes that single line to `/output/entry.txt`, checks it is 1–200 characters, a single line with no leading or trailing whitespace and no double spaces, exactly one sentence ending with a period, opens with "Tip:", speaks about the reader's agent and names how long the wait has lasted, and reads the file back to confirm the write is byte-identical.
